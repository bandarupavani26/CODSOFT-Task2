# CODSOFT-Task2
Student Information:
Bandaru Pavani is a 2nd Year B.Tech CSE student and aspiring Frontend Developer. She is interested in web designing, responsive websites, and learning modern web development technologies.

Project Overview:
The Pavani Landing Page is a responsive and attractive landing page developed using HTML5 and CSS3. This project is designed to showcase frontend development skills, modern UI design, and responsive layouts with a clean user-friendly interface.

Objective:
To create a professional responsive landing page
To improve HTML and CSS designing skills
To practice responsive web development concepts
To build attractive and user-friendly web interfaces

Features:
Fixed navigation bar
Hero section with background image
About section
Services section
Skills section
Projects section
Contact section
Responsive design for all devices
Hover effects and smooth transitions

Technologies Used:
HTML5
CSS3
Flexbox
CSS Grid
Media Queries

Functions :
Semantic HTML tags
Responsive layouts
Flexbox alignment
CSS Grid system
Hover effects
Smooth transitions
Fixed header navigation
Background overlay effects

Advantages:
Creates a professional online presence
Improves frontend development skills
Mobile-friendly design
Easy to customize and update
Attractive modern user interface

Applications:
Landing page design
Student portfolio showcase
Web design practice project
Internship project submission
Personal branding website

Conclusion:
This landing page project helps in understanding the fundamentals of frontend web development using HTML and CSS. It improves responsive web designing skills and provides experience in creating attractive and professional websites with modern layouts.
